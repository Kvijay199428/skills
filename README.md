# Awesome AI Skills Collection 🚀

Welcome to the **Skills Collection**! This repository houses a curated set of specialized AI skills, prompts, workflows, and frontend assets designed to supercharge your development, testing, and design workflows when working with agentic AI and modern applications.

## 📂 Repository Contents

Here is a detailed breakdown of the skills and tools available in this repository:

### 1. 🛠️ Github Project Manager (`github-project-manager/`)
A repository-governance and Git/GitHub workflow skill for managing any project's version control lifecycle. 
- **What it does**: Handles branch strategy, commits, pull requests, merges, tags, and releases.
- **When to use**: Whenever you need help with Git or GitHub operations on a real repository—committing changes, deciding what to branch, opening a PR, merging to production/main, tagging a release, setting up branch protection, or auditing repository state.
- **Safety First**: Enforces a strict workflow against destructive git operations (force push, history rewrite, branch delete, hard reset).

### 2. ✍️ Prompt Master (`prompt-master/`)
An expert prompt-generation skill for various AI tools.
- **What it does**: Generates optimized prompts for AI tools (LLMs, Cursor, Midjourney, image/video AI, coding agents). 
- **When to use**: Activates when explicitly asked to write, fix, improve, or adapt a prompt for a specific AI tool with zero wasted tokens, acting purely as a Prompt Engineer.

### 3. 🎨 Skills For Designers & Engineers (`skills-main/`)
A comprehensive suite of UI and animation skills (curated by Emil Kowalski) to help build better user interfaces.
- **What it does**: Helps developers and designers make the right choices regarding animations, Apple-style design, prototype building, and overall UI polishing.
- **Sub-skills include**: `animate`, `animate-expo`, `animation-vocabulary`, `apple-design`, `pick-ui-library`, `prototype`, `review-animations`, `write-swift`, and more.

### 4. 🧪 Smoke Testing (`smoke-testing/`)
A persistent, read-only, evidence-based smoke testing skill.
- **What it does**: Runs non-destructive health checks on web applications (React/Vite/Next frontend + FastAPI/Django/Spring/Express backends).
- **When to use**: To verify a build isn't broken before deep testing, set up CI smoke testing, or execute a sanity check. It tracks its own TODOs, creates Markdown/JSON reports, and *never* modifies application code without explicit user approval.

### 5. 🔍 Testing, Audit & Debugging Protocol (`testing-audit-debugging-protocol/`)
A professional-grade testing, audit, debugging protocol, and full QA orchestrator.
- **What it does**: Discovers, selects, tests, investigates, documents, and reports on application health. It enforces a strict approval-gated workflow (`DISCOVER -> TEST -> REPRODUCE -> DOCUMENT -> AUDIT -> PROPOSE FIX -> APPROVAL -> EDIT`).
- **Features**: Includes a self-contained library of nested specialist skills, maintains project-side audit memory, applies confidence thresholds, supports audit replay, and manages database schema/index standard checks.

### 6. ✨ Transitions.dev (`transitions.dev-main/`)
An interactive collection of reusable, high-quality CSS transitions.
- **What it does**: Demonstrates different interaction patterns (e.g., card resize, number pop-in, notification badge, menu dropdown) and ships a copy-ready, portable CSS snippet for each.
- **Use case**: When you need smooth, professional-grade animations and transitions for your web applications.
